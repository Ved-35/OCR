# React + Vite Frontend

This project was created with React, Vite, TypeScript, and a modern Vanilla CSS design system.

## Available Scripts

In the project directory, you can run:

### `npm run dev`
Runs the app in development mode at [http://localhost:5173](http://localhost:5173).  
Configured with API proxy to proxy `/api` calls to Node.js backend on `http://localhost:5000`.

### `npm run build`
Builds the app for production to the `dist` folder.

### `npm run preview`
Locally preview the production build.
